# 我的 Docker 手冊

Docker／Docker Compose 的常用指令與使用情境。直接用瀏覽器開 `index.html` 即可（不需要伺服器）。

- 上半部：概念地圖，加上依「我想要⋯」整理的指令卡片（啟動停止、看 log、進容器、讓設定生效、image 版本、volume、網路、override、開機啟動⋯）。
- 下半部：使用情境，遇到問題時一步一步照著做（改設定沒生效、部署時 git pull 失敗、鎖版本、資料庫升版、資料庫看起來被清空⋯）。

按 `/` 可以搜尋，`Esc` 清除搜尋。

指令以 Docker 29.8、Docker Compose v5.5 確認過；舊版 `docker-compose`（中間是橫線）大多也適用。
